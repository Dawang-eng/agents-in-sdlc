フィルタリング機能の実装、指示の更新、スキルの更新、品質保証 (QA) プロファイル、テストを 1 つのブランチに保存しました。これらをまとめてレビューし、プルリクエストを作成します。星評価のプルリクエスト (PR) は自分でマージしましたが、今回は **Agent Merge** にプロセスの管理を任せます。

> [!NOTE]
> 通常は、機能、指示の更新、スキルの更新、QA エージェントを複数の PR に分けます。ワークショップを簡潔に進めるため、フィルタリングと品質のワークフロー全体を 1 つのセッションとブランチにまとめ、そのすべての作業をこの PR に含めています。

このレッスンでは、次の操作を行います。

- Agent Merge と、マージのライフサイクルを自動化する仕組みを学ぶ。
- 機能の PR 全体と検証結果を確認する。
- レビュー後にのみ Agent Merge を許可し、PR がマージされたことを確認する。

## シナリオ

フィルタリング機能のワークフローを通じて、Copilot を使って機能を計画、実装、検証しました。Tailspin Toys では、マージを許可するかどうかは開発者が管理しながら、残りの PR 作業を自動化したいと考えています。

## Agent Merge について

**Agent Merge** は、GitHub Copilot app でプルリクエストをマージするまでに必要な残りの作業を自動化します。有効にすると、アプリのセッションがプルリクエストを読み取り、失敗した継続的インテグレーション (CI) チェックの修正、レビュー コメントへの対応、必要に応じたリベースなど、マージを妨げている問題に対処します。GitHub が許可するとマージを行います。バックグラウンドで実行され、アプリを再起動しても継続し、PR がマージされると自動的に停止します。

ここまでは、自分で **Merge pull request** を選んでいました。Agent Merge に作業を任せることもできますが、コードの編集やマージには引き続き明示的な許可が必要です。マージを許可する前に、実行できる操作と作業内容を確認してください。

## Agent Merge で PR を管理する

コードの作成とレビューが完了したので、Agent Merge に PR のプロセスを管理させましょう。

1. エージェント ピッカーで **Default agent** を選びます。
2. **Create PR** の横にあるドロップダウンを選びます。
3. **Agent Merge** を選びます。ボタンが **Agent Merge** に変わります。
4. **Agent Merge** ボタンを選び、プロセスを開始します。ドロップダウンの項目を選んだだけでは開始されません。

Agent Merge が開始され、次の処理を行います。

- タイトルと説明を付けてプルリクエストを作成する。
- Issue からセッションを開始した場合は、説明本文で関連する Issue を参照する。
- ターゲット ブランチにリベースするか、マージ競合に対処する。
- CI を監視し、すべてのチェックが成功するようにする。
- 他の開発者や Copilot code review からのフィードバックがないか PR を監視し、コメントを解決するために更新する。
- すべての処理が成功した後、必要に応じて PR を自動的にマージする。

すべてのチェックが成功したら、Agent Merge に PR もマージさせましょう。

5. マージを許可する前に、PR の差分と検証結果をレビューします。
6. **Agent Merge** の横にあるドロップダウンを選びます。
7. **Merge pull request** の横にチェックが付いていることを確認します。
8. エージェントに明示的にマージを依頼します。

    ```plaintext
    Merge the PR once all required checks and approvals pass. Do not bypass repository protections.
    ```

9. 進行状況を確認し、報告された問題を解決します。次に進む前に、エージェントが実行中であることやマージ許可が有効であることだけで判断せず、PR の状態が **Merged** になったことを確認します。

> [!IMPORTANT]
> Agent Merge は、リポジトリの保護設定や権限不足を回避しません。続行する前に、それらの問題を解決してください。

- Agent Merge と、マージのライフサイクルを自動化する仕組みを学びました。
