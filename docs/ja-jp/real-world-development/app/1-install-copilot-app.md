**[GitHub Copilot app][about-copilot-app]** は、エージェント主導の開発に使うデスクトップ アプリケーションです。GitHub Copilot CLI を基盤として GitHub とネイティブに統合されているため、リポジトリ、ブランチ、CI パイプラインをすぐに利用できます。複数のエージェントを個別の分離されたワークスペースで並行して動かし、作業を指示するワークフローに適しています。繰り返し作業の自動化にも使えます。Node.js のインストールとプロジェクトの準備ができたので、次はアプリをインストールしてリポジトリを接続します。

このレッスンでは、次の操作を行います。

- GitHub Copilot app をインストールしてサインインする。
- GitHub リポジトリからプロジェクトをアプリに追加する。
- テンプレートで用意されたバックログなど、ワークスペースの構成を確認する。
- クイックチャットを試し、アプリについて質問する。

## シナリオ

チームは、増え続けるバックログに取り組むため、AI エージェントを導入しています。Copilot app では、Issue を選び、エージェントを実行し、変更をレビューし、プルリクエストをマージするまで、一か所から作業を指示できます。このレッスンでは、アプリをインストールして接続し、プロジェクトについての会話を始める準備をします。

> [!NOTE]
> 対象の Copilot プランが必要です。**Copilot Free**、**Copilot Student**、またはいずれかの有料プラン (Pro、Pro+、Business、Enterprise) を利用してください。Copilot Business または Copilot Enterprise を使う場合、管理者が **GitHub Copilot app** ポリシーを有効にしておく必要があります。

## GitHub Copilot app をインストールして構成する

GitHub Copilot app を使うには、まずアプリをインストールします。Windows、macOS、Linux 向けのバージョンが用意されています。アプリをインストールして認証し、Tailspin Toys リポジトリを追加しましょう。

1. ブラウザーで [GitHub Copilot app のランディング ページ][download-app]を開きます。
2. 使用しているプラットフォーム向けのアプリをダウンロードし、ページに記載された手順に従ってインストールします。
3. インストール後、アプリを開きます。
4. **Sign in to GitHub** を選び、画面の指示に従って認証します。データ所在地が設定された GitHub Enterprise Cloud を使う場合は、**Use GitHub Enterprise** を選び、プロンプトに従って `*.ghe.com` のホスト名を入力します。GitHub Enterprise Server はサポートされていません。
5. オンボーディング中にリポジトリの選択画面が表示されたら、テンプレートから作成した Tailspin Toys リポジトリを選びます。リポジトリの選択をスキップし、オンボーディング完了後に追加してもかまいません。
6. テーマの選択を求められたら選び、オンボーディングを完了します。
7. サイドバーの **Sessions** にリポジトリが表示されているか確認します。すでに表示されている場合は、もう一度追加する必要はありません。
8. リポジトリがまだ接続されていない場合は、**Sessions** の横にある **+** を選んで新しいセッションを作成し、**Add GitHub repository** を選びます。前提条件のレッスンで控えた Owner とリポジトリ名を入力します。
9. リポジトリがサイドバーに表示されることを確認します。このレイアウトでは、`tailspin-toys` などのリポジトリ フォルダーが **Sessions** の下にグループ化され、個々のセッションは各リポジトリの下に表示されます。

## ワークスペースを確認する

プロジェクトを接続したら、アプリの使い方を確認しましょう。サイドバーは、いくつかの領域に分かれています。

- **New** - 新しいチャット セッションを開始します。
- **Pull requests** - アプリの GitHub ネイティブ統合を通じて表示されるプルリクエストです。アプリを離れずに、プルリクエストを参照して絞り込み、CI の状態を確認し、レビューできます。
- **Issues** - 同じように表示される Issue です。Issue を参照して絞り込み、Issue からセッションを開始できます。
- **Automations** - スケジュールまたはオンデマンドで実行する、保存済みのエージェント タスクです。To Do リストの管理、定期的なプロジェクト保守、面倒な作業の委任に使えます。まとめでは次のステップとして紹介しますが、ワークショップ内の演習ではありません。
- **Customize** - MCP サーバー、プラグイン、スキルなどのコンポーネントを追加して、Copilot app の機能を拡張します。Playwright MCP の設定で使います。
- **Chats** - 独自のブランチやワークスペースを必要としない、質問やブレインストーミング向けの軽い会話です。最初のチャットを始めると、この項目が表示されます。表示されていない場合は、**Sessions** の横にある **+** を選んで最初のチャットを始めます。
- **Sessions** - リポジトリ フォルダーと、その下のエージェント セッションをまとめます。`tailspin-toys` などのリポジトリ名を選ぶとリポジトリ ビューが開きます。リポジトリ名の下にあるセッションを選ぶと、その会話に戻ります。各セッションは分離された独自のワークスペースで動作するため、複数のセッションを同時に実行しても変更は競合しません。星評価の追加で、最初のセッションを開始します。

ワークショップを進めながら、ワークスペースを確認していきます。

> [!TIP]
> 迷ったときは Copilot に質問してください。操作方法が分からない場合や、何かが可能かどうか知りたい場合は、Copilot が案内してくれます。

### 登録済みのバックログを確認する

バックログのないプロジェクトはほとんどなく、Tailspin Toys も例外ではありません。テンプレートを作成したときに追加されたバックログを確認しましょう。

1. サイドバーの **Sessions** で、個別のセッションではなく Tailspin Toys のリポジトリ フォルダーを選びます。次に、リポジトリ上部のナビゲーションで **Issues** を選びます。
2. Issue 番号を決めつけず、次のタイトルを探します。

   - Allow users to filter games by category and publisher
   - Update our repository coding standards

3. Issue を選んで詳細を読みます。各 Issue はエージェント セッションの開始点にもなります。小規模な最初の変更が終わったら、フィルタリング Issue から作業を開始します。

> [!NOTE]
> **Issues** と **Pull requests** の一覧は自動的に絞り込まれ、Copilot app に追加したリポジトリの項目だけが表示されます。ほかのリポジトリの作業項目も表示するには、そのリポジトリをアプリに追加してください。

## クイックチャットを試す

アプリに慣れるには、アプリ自体について質問するのもよい方法です。**クイックチャット**を使うと、ブランチや worktree を作成せずに質問やブレインストーミングができます。セッションを必要としない、その場限りの簡単な質問に適しています。

1. サイドバーの **Chats** の横にある **+** を選んで、新しいチャットを開きます。**Chats** がまだ表示されていない場合は、**Sessions** の横にある **+** を選んで最初のチャットを始めます。開始後に **Chats** が表示されます。
2. アプリのセッションの仕組みについて、次のように質問します。

   ```plaintext
   How does the GitHub Copilot app use worktrees?
   ```

3. 会話ビューで回答を読みます。各セッションが分離された独自の Git worktree で実行されるため、変更が競合せずに複数のエージェントを並行して動かせることが分かります。会話は続けることも、新しいチャットを始めることもできます。

## まとめと次のステップ

GitHub Copilot app をインストールしてプロジェクトを接続し、ワークスペースを確認しました。次の操作を行いました。

- アプリをインストールして GitHub にサインインしました。
- GitHub リポジトリからプロジェクトを追加しました。
- ワークスペースを確認し、**Issues** で登録済みのバックログを見つけました。
- クイックチャットで、その場限りの簡単な質問をしました。

次は、[最初のエージェント セッション][next-lesson]を開始し、ゲーム カードに星評価を表示する変更を加えます。
